# 🎓 TechFest 2026 – Event Announcement

## 🌟 About the Project

TechFest 2026 is an annual technical event organized by the
Department of Computer Science.

This project is a simple event announcement webpage created using
HTML and CSS.

## 🚀 Features

- 🎓 TechFest 2026 heading
- 📢 Annual Technical Festival subtitle
- 📝 Event introduction
- 📅 Event date and time
- 📍 Event venue
- ⚠️ Registration notice
- 💻 Technical activities
- 🎨 CSS text styling

## 📅 Event Details

| Detail | Information |
|---|---|
| 📅 Date | 15 October 2026 |
| ⏰ Time | 10:00 AM onwards |
| 📍 Venue | Main Auditorium |

## 🎯 Activities

The event includes:

- 💻 Coding Contest
- 🌐 Web Design Challenge
- 🐞 Debugging Challenge
- 🧠 Technical Quiz

## ⚠️ Important Notice

**Registration is mandatory for all participants.**
